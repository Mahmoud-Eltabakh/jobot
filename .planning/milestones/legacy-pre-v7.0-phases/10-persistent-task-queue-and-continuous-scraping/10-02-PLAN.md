# Plan 10-02: Async Continuous Queue Worker Loop

## Objective
Build background worker daemon consuming queued scraping and scoring tasks continuously.

## Tasks
1. Create `app/queue/worker.py` with `QueueWorker` class.
2. Implement task handlers for `scrape_query` (invoking `JobSpy` and `StepStone`) and `evaluate_job` (invoking `JobEvaluator`).
3. Wire background queue worker into FastAPI `lifespan` in `app/main.py`.
4. Ensure graceful shutdown and in-flight task safety.

# Plan 10-03: Queue Monitoring REST API & Web Dashboard Indicators

## Objective
Expose real-time queue endpoints and add a live status widget to the top navigation bar and dashboard.

## Tasks
1. Create `app/api/queue.py` with `GET /api/queue/status`, `POST /api/queue/enqueue`, and `POST /api/queue/retry-failed`.
2. Register `queue_router` in `app/main.py`.
3. Update `templates/base.html` and `templates/index.html` with a live HTMX polling indicator showing in-progress tasks and pending queue items.

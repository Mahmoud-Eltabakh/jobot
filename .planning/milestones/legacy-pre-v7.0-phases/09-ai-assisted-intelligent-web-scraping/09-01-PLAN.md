# Plan 09-01: AI DOM & HTML Structured Job Extractor

## Objective
Build `AIScraperExtractor` capable of parsing raw rendered HTML or text from any job listing page and returning structured job data with normalized salary, remote status, and required tech stack using LLM.

## Tasks
1. Create `app/scrapers/ai_extractor.py` with `AIScraperExtractor` class.
2. Define structured Pydantic schema for `AIExtractedJobListing` (`title`, `company`, `location`, `is_remote`, `salary_min`, `salary_max`, `salary_currency`, `description`, `required_skills`, `visa_sponsorship`, `language_requirement`, `is_legitimate_job`).
3. Implement HTML-to-clean-text preprocessing to reduce token footprint while preserving semantic structure.
4. Add offline/mock heuristic fallback for test and non-AI runs.

# Plan 07-03: Dynamic Skill-Driven Scraping Query Builder

## Objective
Enable Jobot scrapers (JobSpy for LinkedIn/Google and StepStone) to dynamically generate and execute search queries based on the candidate's target titles and active profile skills.

## Tasks
1. Implement `build_profile_search_queries` in `app/scrapers/scheduler.py`.
2. Generate role + skill search pairs (e.g. `Python Developer FastAPI`, `Backend Engineer Docker`).
3. Allow user-selected active search skills to influence query combinations.
4. Pass dynamic queries to `JobSpyScraper` and `StepStoneScraper`.

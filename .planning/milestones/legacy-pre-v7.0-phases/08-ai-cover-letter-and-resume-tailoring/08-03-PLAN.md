# Plan 08-03: Job Inspector UI Cover Letter & Tailoring Tabs

## Objective
Enhance the Job Inspector slide-over drawer with interactive tabs for generating, editing, and copying tailored cover letters and resume bullets.

## Tasks
1. Update `templates/components/job_inspector.html`:
   - Add sub-tabs: `Overview`, `Cover Letter`, `Tailored CV`, `Notes & History`.
   - "Generate Cover Letter" button with tone selector (Professional, Direct, Conversational).
   - "Tailor Resume Points" button.
   - Markdown preview and inline editable textarea.
   - 1-Click "Copy to Clipboard" button.
2. Add HTMX endpoints in `app/web/routes.py`:
   - `GET /web/job/{job_id}/cover-letter`
   - `POST /web/job/{job_id}/cover-letter/generate`
   - `POST /web/job/{job_id}/tailor-resume/generate`
   - `POST /web/job/{job_id}/materials/save`

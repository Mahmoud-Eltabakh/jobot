# Plan 08-02: REST API & Application Generation Pipeline

## Objective
Implement REST API endpoints for generating, updating, retrieving, and deleting job-specific cover letters and tailored resume points.

## Tasks
1. Create `app/api/applications.py`:
   - `POST /api/jobs/{job_id}/cover-letter/generate` (accepts tone, custom instructions).
   - `POST /api/jobs/{job_id}/tailor-resume/generate`.
   - `GET /api/jobs/{job_id}/materials` (fetches existing saved application materials).
   - `PUT /api/materials/{material_id}` (updates content markdown).
2. Register `applications_router` in `app/main.py`.
3. Unit test generation pipeline with `MockAIClient`.

# Plan 08-01: Application Artifact Data Model & Prompt Architecture

## Objective
Create the database models for storing generated application materials (cover letters and tailored resume points) and define prompt templates for LLM generation.

## Tasks
1. Add `ApplicationMaterial` SQLModel in `app/db/models.py` (fields: `id`, `job_id`, `material_type` ['cover_letter', 'tailored_resume'], `content_markdown`, `tone`, `created_at`, `updated_at`).
2. Add migration helper in `app/db/database.py` for new tables and columns.
3. Create `app/ai/application_generator.py` with `ApplicationGenerator` class:
   - System prompts for professional, enthusiastic, and direct cover letters.
   - Resume tailoring prompts aligning candidate profile with specific job descriptions and missing skill recommendations.
   - Fallback generator for offline/mock environments.

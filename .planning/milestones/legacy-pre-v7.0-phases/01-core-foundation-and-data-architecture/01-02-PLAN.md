<task type="auto">
  <name>Task 1: Define relational SQLModel entities in app/db/models.py</name>
  <files>app/db/models.py</files>
  <action>
    Create SQLModel entity classes with type annotations, table=True, foreign keys, and indexes:
    1. `JobStatus` (Enum): `SEEN = "seen"`, `APPLIED = "applied"`, `NOT_A_FIT = "not a good fit"`, `REJECTED = "rejected"`, `INTERVIEW_1 = "1. interview"`, `INTERVIEW_2 = "2. interview"`, `INTERVIEW_3 = "3. interview"`, `WAITING = "waiting for respond"`.
    2. `Job` (table):
       - `id`: Optional[int] (primary key)
       - `source`: str (e.g. "linkedin", "stepstone", "google")
       - `source_id`: Optional[str] (external board id)
       - `title`: str (indexed)
       - `company`: str (indexed)
       - `location`: str
       - `is_remote`: bool (default False)
       - `salary_min`: Optional[float]
       - `salary_max`: Optional[float]
       - `salary_currency`: Optional[str]
       - `url`: str (indexed, unique where possible)
       - `description`: str
       - `fit_score`: Optional[int] (0-100)
       - `fit_summary`: Optional[str]
       - `pros_json`: Optional[str] (serialized list)
       - `cons_json`: Optional[str] (serialized list)
       - `missing_skills_json`: Optional[str] (serialized list)
       - `status`: str (default "seen", indexed)
       - `dedup_hash`: str (unique index on SHA256 of normalized company+title+location)
       - `created_at`: datetime (default utcnow)
       - `updated_at`: datetime (default utcnow)
    3. `JobStatusHistory` (table):
       - `id`: Optional[int] (primary key)
       - `job_id`: int (foreign key to job.id, indexed)
       - `old_status`: Optional[str]
       - `new_status`: str
       - `notes`: Optional[str]
       - `created_at`: datetime (default utcnow)
    4. `UserProfile` (table):
       - `id`: Optional[int] (primary key)
       - `full_name`: str
       - `target_titles_json`: str (JSON list)
       - `target_locations_json`: str (JSON list)
       - `target_salary_min`: Optional[float]
       - `skills_json`: str (JSON list)
       - `cv_raw_text`: Optional[str]
       - `linkedin_url`: Optional[str]
       - `updated_at`: datetime (default utcnow)
    5. `SearchConfig` (table):
       - `id`: Optional[int] (primary key)
       - `source`: str ("linkedin", "stepstone", "google")
       - `keywords`: str
       - `location`: str
       - `interval_hours`: int (default 12)
       - `is_active`: bool (default True)
       - `last_run_at`: Optional[datetime]
    6. `FeedbackNote` (table):
       - `id`: Optional[int] (primary key)
       - `job_id`: int (foreign key to job.id)
       - `sentiment`: str ("positive", "negative", "neutral")
       - `note_text`: str
       - `created_at`: datetime (default utcnow)
    7. `FilterRule` (table):
       - `id`: Optional[int] (primary key)
       - `rule_type`: str ("title", "keyword", "company")
       - `pattern`: str (e.g. "Senior", "PHP", "Lead")
       - `is_regex`: bool (default False)
       - `is_active`: bool (default True)
       - `created_at`: datetime (default utcnow)
    8. `AppSettings` (table):
       - `key`: str (primary key, e.g. "ai_provider", "ollama_model", "ollama_base_url", "openai_api_key", "openai_model")
       - `value_json`: str (serialized string / number / object)
       - `description`: Optional[str]
       - `updated_at`: datetime (default utcnow)
  </action>
  <verify>python -c "from app.db.models import Job, JobStatus, UserProfile, SearchConfig, FeedbackNote, FilterRule, AppSettings; print('Models imported successfully')"</verify>

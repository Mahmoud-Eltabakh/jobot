<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone → SSH tunnel | remote UI session is encrypted |
| host → local web app | only the private target app is forwarded |
| tunnel → internet | no direct exposure of the worker stack or database |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-------------|-----------------|
| T-13-06 | Spoofing | SSH + browser session | mitigate | verify host identity and use key-based auth |
| T-13-07 | Tampering | forwarded port | mitigate | bind only to the required local endpoint and keep host-only routing |
| T-13-08 | Information Disclosure | local URL | mitigate | do not publish the local app address outside the tunnel |
| T-13-09 | DoS | mobile reconnect storm | accept | use normal SSH connection limits and timeouts |
</threat_model>

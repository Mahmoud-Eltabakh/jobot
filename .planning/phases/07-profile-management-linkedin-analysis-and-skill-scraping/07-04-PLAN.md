# Plan 07-04: Profile Editing Web Dashboard Tab

## Objective
Implement a dedicated Profile management view in the web UI with interactive skill management, target roles editing, and LinkedIn sync controls.

## Tasks
1. Add "Profile" tab to the top navbar in `templates/base.html`.
2. Create `templates/components/profile.html` featuring:
   - Personal details, headline, bio, experience years, minimum salary, work model.
   - Interactive Target Titles tag manager.
   - Core Skills list with toggles to enable/disable specific skills in scraper searches.
   - LinkedIn Profile URL & sync card with real-time status.
3. Wire `/web/views/profile` in `app/web/routes.py`.
4. Provide HTMX form endpoints for live inline updates and feedback.

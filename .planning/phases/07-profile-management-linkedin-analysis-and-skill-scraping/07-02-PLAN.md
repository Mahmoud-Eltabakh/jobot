# Plan 07-02: LinkedIn Profile Ingestion & AI Analyzer

## Objective
Build `LinkedInProfileAnalyzer` capable of ingesting LinkedIn profile data (via URL, session cookie, Playwright, or text) and extracting structured profile attributes using AI.

## Tasks
1. Create `app/ai/linkedin_analyzer.py` with `LinkedInProfileAnalyzer`.
2. Implement Playwright-based scraper and cookie-authenticated extractor.
3. Add LLM analysis prompt for LinkedIn headlines, about sections, experience items, and skills.
4. Integrate with `UserProfile` and `ProfileEmbedder` for immediate database and vector storage update.
5. Provide API endpoint `POST /api/profile/linkedin/sync`.

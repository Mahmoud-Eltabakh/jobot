<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| phone → SSH tunnel | Untrusted remote device connects through an encrypted tunnel |
| tunnel → local app | The remote connection reaches the host-only UI endpoint |
| host → DB/AI services | Local services remain private and not directly exposed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-------------|-----------------|
| T-13-01 | Spoofing | SSH auth | mitigate | require key-based authentication and host validation |
| T-13-02 | Tampering | tunnel config | mitigate | restrict forwarding to the application port only |
| T-13-03 | Information Disclosure | local app and DB | mitigate | keep all services local and bind to loopback or tunnel-only endpoints |
| T-13-04 | Denial of Service | remote client access | mitigate | keep a clear authentication and session policy and avoid public exposure |
| T-13-05 | Elevation of Privilege | host config | mitigate | do not grant shell access beyond tunnel usage and avoid broad permissions |
</threat_model>

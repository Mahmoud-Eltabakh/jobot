## Tasks

### Task 1: Hosted onboarding and personal workspace flow

- define the first-run flow for a private-beta user
- ensure account state, workspace state, and profile assignment are persistent and user-scoped
- capture how onboarding differs from self-hosted mode

Outcome: onboarding is explicit and versioned for the hosted beta.

### Task 2: Job discovery and fit workflow

- connect profile, job discovery, and fit review to the user workspace
- define how sources are disclosed and how mismatches are surfaced
- enforce user-scoped job and profile actions

Outcome: the core beta user workflow is complete and isolated to the authenticated user.

### Task 3: Managed AI controls and quota UX

- implement quota tracking and visible remaining budget/state
- define provider failure behavior and fallback prompts
- ensure AI-generated outputs are clearly ownership-bound and explainable

Outcome: budget and runtime state are visible to the user without hidden failures.

### Task 4: Export, deletion, and user control paths

- implement export and delete actions for generated materials and user-owned data
- capture retention notices and what cannot be cleaned up automatically
- validate that these actions are scoped to the current user and current workspace

Outcome: the user has clear ownership and control over their beta data.

## Exit Criteria

Phase 22 is complete when the hosted beta workflow is operable, quota-aware, and explicit about failure and ownership boundaries.

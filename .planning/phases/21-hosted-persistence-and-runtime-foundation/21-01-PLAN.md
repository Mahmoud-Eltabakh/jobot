## Tasks

### Task 1: Audit current persistence and queue patterns

- review all persisted user-owned entities and runtime task state
- identify which components are local-only and which are ready for hosted use
- list required migration boundaries between SQLite and managed hosted storage

Outcome: an ownership and durability map for the hosted runtime is captured.

### Task 2: Define hosted database and queue model

- select the durable hosted state model for tasks, profile data, and generated artifacts
- define multi-worker safety: leases, idempotency, retries, and ownership checks
- record where vector storage remains local or shifts to a managed model

Outcome: the runtime architecture is documented as a production-ready hosted foundation.

### Task 3: Define recovery, backup, and rollback contracts

- specify key backup and restore responsibilities for DB, vector store, provider artifacts, and exports
- define rollback boundaries for schema and task-state migration issues
- define operational checkpoints before enabling hosted beta workflows

Outcome: the beta runtime has a recoverable, reviewable operational contract.

### Task 4: Validate compatibility for self-hosted mode

- document the local-first/system-on-a-machine mode that remains supported
- define intentional divergence and compatibility expectations between local and hosted modes
- capture no-go conditions if the local path cannot be maintained safely

Outcome: the self-hosted path remains explicit, not accidental.

## Exit Criteria

Phase 21 is complete when the hosted persistence model is durable, recoverable, and documented with a clear compatibility story for self-hosted use.

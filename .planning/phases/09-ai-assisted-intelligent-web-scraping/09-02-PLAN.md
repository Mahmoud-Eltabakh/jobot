# Plan 09-02: AI Query Strategist & Platform-Specific Search Optimizer

## Objective
Build `AIQueryStrategist` to automatically generate optimized, platform-tuned search queries (LinkedIn, StepStone, Google Jobs) using the candidate's active skills, target titles, and negative blacklists.

## Tasks
1. Create `app/scrapers/query_strategist.py` with `AIQueryStrategist`.
2. Implement platform-tailored query generation (e.g. Boolean strings for LinkedIn, location/skill keywords for StepStone and Google Jobs).
3. Integrate with candidate `UserProfile` and `FilterRule` blacklist rules.
4. Add caching and fallback heuristics.

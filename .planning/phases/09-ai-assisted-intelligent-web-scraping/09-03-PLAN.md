# Plan 09-03: Hybrid Scraper Pipeline Integration with Playwright & JobSpy

## Objective
Integrate `AIScraperExtractor` and `AIQueryStrategist` into `ScraperPipeline` and `StepStoneScraper` to enable AI-assisted web scraping on demand and in background runs.

## Tasks
1. Update `StepStoneScraper` in `app/scrapers/stepstone.py` to use `AIScraperExtractor` when standard CSS selectors fail or return partial fields.
2. Update `ScraperPipeline` in `app/scrapers/scheduler.py` to use `AIQueryStrategist` for intelligent search queries and run AI extraction on raw job detail pages.
3. Add configuration toggle `use_ai_scraping` in `AppSettings`.
4. Ensure full backward compatibility with JobSpy and fast-path selectors.
